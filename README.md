# Pokémon Incanto

Gioco amatoriale di aste Pokémon per due giocatori: si comprano all'asta 6 Pokémon a testa e si esportano le squadre per Pokémon Showdown.
*Amateur two-player Pokémon auction game: buy 6 Pokémon each at auction and export the teams to Pokémon Showdown.*
